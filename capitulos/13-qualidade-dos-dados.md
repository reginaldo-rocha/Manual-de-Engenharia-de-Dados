# 📖 Capítulo 13

# Qualidade dos Dados

## Introdução

Dados confiáveis são fundamentais para qualquer tomada de decisão.

Mesmo uma arquitetura moderna perde valor quando trabalha com informações incorretas ou inconsistentes.

---

## O que é qualidade dos dados?

É o conjunto de características que torna um dado confiável para uso.

Entre elas estão:

- Precisão.
- Consistência.
- Integridade.
- Atualização.
- Completude.

---

## Por que é importante?

Dados de baixa qualidade podem gerar:

- Decisões equivocadas.
- Retrabalho.
- Perda de credibilidade.
- Indicadores incorretos.

Garantir qualidade significa reduzir esses riscos.

---

## O papel do Engenheiro de Dados

O Engenheiro de Dados implementa processos de validação, monitoramento e tratamento para assegurar que os dados estejam corretos antes de serem consumidos.

---

## Conclusão

A confiança nos dados depende diretamente da qualidade com que eles são coletados, transformados e disponibilizados.
