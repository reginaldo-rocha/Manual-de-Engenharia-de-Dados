# 📖 Capítulo 15

# Agora Sim, o SQL

## Introdução

Após compreender o negócio, definir requisitos, conhecer as fontes de dados e planejar a solução, chega o momento da implementação.

O SQL deixa de ser o ponto de partida e passa a ser uma ferramenta para executar o planejamento realizado.

---

## O papel do SQL

O SQL permite consultar, transformar e organizar os dados de acordo com as necessidades do projeto.

Ele é uma das principais ferramentas do Engenheiro de Dados, mas não substitui o entendimento do problema de negócio.

---

## Muito além dos comandos

Conhecer a sintaxe é importante.

Saber quando, por que e como utilizá-la é o que diferencia um profissional técnico de um verdadeiro Engenheiro de Dados.

---

## Conclusão

O SQL transforma planejamento em execução.

Quando utilizado no momento certo, torna-se uma poderosa ferramenta para entregar valor ao negócio.
